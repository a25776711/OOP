## 遊戲介紹
《植物大戰殭屍》是一款結合策略與塔防元素的遊戲。玩家需要運用各種功能不同的植物，佈局在自家草坪上，阻止一波波來襲的殭屍大軍。遊戲節奏輕快、畫風幽默，每個關卡都需要動腦思考資源配置與防守策略
### 遊戲規則
玩家的目標是利用各種植物防禦殭屍的入侵，保護自己的家園不被突破
基本規則：
陽光是資源：玩家需蒐集從天而降的陽光，或種植向日葵產生更多陽光，用來種植植物。  
種植植物：使用陽光在草地上種植不同功能的植物，如發射子彈的豌豆射手、能爆炸的櫻桃炸彈、防禦用的堅果牆等。  
抵擋殭屍：殭屍會從右側進攻，逐步往左移動，玩家必須合理佈局植物將其擊退。  
關卡勝利：當所有殭屍被擊敗，即可通關並解鎖新的植物與關卡。  
關卡失敗：若有殭屍突破最左邊的防線（通常是草地盡頭），則視為失敗。  

特殊關卡:
第5關-堅果保齡球: 植物只會有堅果牆，丟出去可以擊倒僵屍，紅色的堅果牆碰到僵屍會爆炸。

作弊按鈕:

D : 所有僵屍死亡  
S : 所有僵屍被炸死  
J : 增加太陽數量  
K : 一隻僵屍前進  
C : 重置所有植物冷卻
Enter : 開始後即可跳關
Q ： 失敗後按下即可回到遊戲開始畫面

### 問題與解決方法

素材不夠 : 用繪圖軟體一張一張截圖  
畫面移動時每個物件移動步數不同 : 發現切換畫面時物件沒有成功被remove掉  
植物攻擊頻繁抓取殭屍位置，導致遊戲卡頓 : 將殭屍位置做成變數直接傳入，減少抓取動作  
殭屍攻擊判斷無法正常切換狀態 : 把攻擊判斷改為偵測最近的植物位置而不是判斷這個位置有無植物
